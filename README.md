# 🚗 Stat

Stat is a full-stack multilingual car rental platform built with the MERN stack. Users can securely register using Email OTP Verification or Google Authentication, browse available vehicles, check real-time availability, and book cars for custom date ranges.

The platform supports Hindi and English languages, secure JWT authentication, ImageKit-powered image management, and a scalable backend architecture designed for real-world deployment.

### Key Features

✅ Email OTP Verification  
✅ Google Authentication  
✅ JWT Authentication  
✅ Car Listing & Management  
✅ Real-Time Availability Check  
✅ Booking System  
✅ Hindi & English Support  
✅ ImageKit Integration  
✅ MongoDB Atlas Database  
✅ Vercel Deployment
